# 🕐 DateTime API Express

API REST desenvolvida com **Node.js** e **Express.js** para retornar a data e a hora atual.

## 🎯 Objetivo

Criar uma API utilizando Express.js com uma rota responsável por fornecer a data e a hora atual para uma aplicação Front-end.

## 🛠️ Tecnologias

- Node.js
- Express.js
- CORS
- JavaScript
- API REST
- Render

## 🔗 Endpoint

```text
GET /api/data-hora
